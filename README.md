# Costeo Tubo Colapsible

Aplicación web para el costeo detallado de tubos colapsibles con desglose por proceso: Manga, Hombro, Ensamble (Automática), Sellado, Etiquetado, Serigrafía y Logística.

## Funcionalidades

- Parámetros generales editables (kWh, costos fijos, nómina, equipos)
- Cálculo automático de tarifa por segundo de cada equipo
- Costeo por parte con materia prima (peso, g/Kg o componentes por unidad)
- Modelo especial de serigrafía con golpes, setup, tinta y preprensa
- Logística con empaque, transporte y exportación
- Exportación a Google Sheets para histórico

## Uso local

```bash
npm install
npm run dev
```

Se abre en http://localhost:3000
